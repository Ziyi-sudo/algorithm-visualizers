Edit Distance:二维 DP 动画图解

例子:one = "sigh" → two = "asith",答案 2(插入 a,替换 g→t)。
dp[i][j] = 把 one 的前 i 个字符变成 two 的前 j 个字符的最少操作数。

根因① 一张图钉死:i 是「个数 = 长度 = 切口位置」,不是下标

01234 ←切口(个数)
sigh
0123
「前 3 个」= sig = 长度 3 = 切口停在 3,而它的尾字符下标是 2。
切口有 n+1 个,字符只有 n 个 → 数组开 (m+1)×(n+1) 是看出来的,不是背的;
尾字符永远是 charAt(i−1) → 减 1 只发生在「读字符」那一行(边境换算)。

根因② 转移不是背的:盯住两串的尾巴,穷举「最后一步操作」

↖ 替换 replace(+1)把 one 尾换成 two 尾 → 两边尾巴都消掉 → 剩 (i−1, j−1)。尾字符相等时 = 免费白拿,0 代价走同一格。
↑ 删除 delete(+1)删掉 one 的尾 → 只消 one 的尾巴,two 原封不动 → 剩 (i−1, j)。
← 插入 insert(+1)one 尾部插一个 = two 尾的字符 → 只消 two 的尾巴 → 剩 (i, j−1)。
口诀:哪边的尾巴被消掉,哪边的坐标就减一。三个邻居 = 三种操作,一一对应;最后一步是哪种事先不知道 → 三个都算取 min。

DP 表(行 = one 的 i,列 = two 的 j)

点「下一步 ▶」开始:先填 base(有一边是空串),再逐格推,最后从右下角回溯还原每一步操作。
