三个动作，各归各位

  
两道题里那件「在门外做的事」，名字不同、形状一样：Bipartite 是门外染色，Deep Copy 是门外造壳。它们都会写进闸所依据的那个容器，于是递归到门口就被自己刚写下的记录挡了回去——被展开节点的邻居列表根本没打开过。

  
    
    
  1. 写容器 —— 放在函数开头，进门就写跟闸配套。闸问 map，那就只有进了门的人能写 map；门外一个 put 都不留。染色、造壳都属于这一类。
    2. 
    
  2. 递归 —— 放在「它还没被记过」的分支里已经在 map 里，说明它自己那趟跑过或正在跑。环上的节点第二次被撞见时在这里短路，所以不会死循环。
    3. 
    
  3. 连线 / 比色 —— 放在 if 外，无条件执行建节点和连边是两回事，节点已存在 ≠ 边已连上。同理，冲突恰恰只在撞见「已经有颜色的老熟人」时才暴露——把它挪进 if 就等于每次都扭头走开。
    4. 
  

  
判据一句话：染色时机和防重复闸门是配套的一对，拆一半就空转。
