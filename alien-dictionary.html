跟 Course Schedule II 的差别

拓扑排序那一半完全一样。新东西只有两件：图要自己推出来，而且点是字母不是下标。

点：出现过的字母（先扫一遍所有单词收集，别漏了只出现一次的）
边：相邻两个单词第一个不同的字母 c1 → c2

容器要换成 Map，因为点是字符不是 0~n-1 的下标：
    Map<Character, Set<Character>> graph     ← 用 Set 去重,同一条边可能被推出多次
    Map<Character, Integer> inDegree

坑：前缀反序是非法输入
    ["abc", "ab"] —— 长的排在短的前面,逐位比完没有差异,
    但 abc 更长 ⇒ 违反字典序 ⇒ 直接返回 ""

为什么 graph 的 value 用 Set 不用 List：同一对字母关系可能从多对单词里被推出来。用 List 会重复加边，导致 inDegree 被多加几次，永远减不到 0 —— 明明无环却报环。加边前必须判重。

为什么要先扫一遍收集所有字母：只出现在某一个单词里、从没参与过任何比较的字母（比如例 1 里没被比到的），也必须出现在结果里。漏了它们，最后的长度对不上。
